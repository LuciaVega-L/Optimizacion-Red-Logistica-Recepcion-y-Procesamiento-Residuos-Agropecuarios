# Documentación
- `informe-ieee/`: informe técnico en formato IEEE.
- `diagramas/`: diagramas UML del sistema (flujo, clases, secuencia, casos de uso y arquitectura), en Mermaid y PNG.
- `manual-tecnico/`: manual técnico del sistema (instalación, arquitectura, módulos, API y uso), en Word y PDF.
- `formulacion/`: formulación matemática del modelo de transporte y método de solución (símplex y MODI).
- `base-datos/`: guía de la base de datos en Supabase.
